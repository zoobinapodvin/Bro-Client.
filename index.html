Quel jeu est concerné ?

Le projet présenté est un mod cosmétique pour Minecraft Java Edition utilisant Fabric. La version exacte reste à confirmer.

Le mod modifie-t-il le gameplay ?

Le cahier des charges prévoit uniquement des éléments décoratifs locaux, sans avantage en jeu ni action côté serveur.

Quand pourrai-je acheter le mod ?

La boutique n’est pas encore ouverte et les liens de paiement ne sont pas activés.
